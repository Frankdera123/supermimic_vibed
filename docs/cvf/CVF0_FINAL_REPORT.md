## 0. 一句话裁定（对照预注册判定树）

**H-CV2 成立（模型内 Sobolev 失配为主导瓶颈）+ 共享 Critic 评价混淆实锤。**

1. **Critic 标量值极其准确**（$r = +0.987\text{–}0.990$），且 **WM 自身长程闭环续推的一阶梯度与真实 Simulator 也高度一致**（错误不在 WM→Sim 现实鸿沟 B）；
2. **真正失效的是 Critic 从标量拟合到一阶状态梯度的转化（误差项 A）**：在非接触位姿方向（`pose_safe_critic`）以外，Critic 在策略更新真实移动的速度方向（`vel_reachable`）上与真值近似无关甚至反向（`sign = 0.31–0.38`, `Spearman ≈ 0`）；
3. **在可达流形上（Oracle 2），Learned Critic 严重失准并拖垮总梯度**：用真实 Simulator 96 步续推替代共享 learned critic 后，Critic 路径自身仅 `sign = 0.58`（`delta_2300` 仅 `0.50`），并将完整策略梯度的秩相关从动力学路径单独的 `+0.51` 拖垮至 **`+0.08`**；
4. **“Critic 补偿 WM 误差”假说被直接证伪**：$e_{\text{state}}$ 与 $e_{\text{critic}}^{\text{true}}$ 呈正相关 **`r = +0.413`**（而非负相关补偿），此前 CRGF/PADA 测得的高总梯度一致性主要来自 **共享 learned critic 引起的评价混淆**。

## 4. 诚实边界声明

1. 长程续推中因物理接触切换与步态分叉，严格跨 $\epsilon$ 门禁剔除率较高（Oracle 1 `n_gated = 2..10 / 16`；Oracle 2 单集 `n_gated = 1..4 / 16`），但全样本与合并策略集（`n=48`）均给出一致结论；
