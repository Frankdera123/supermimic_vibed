# CVF1B_CRITIC_RESULTS_V2（CVF-1b 修正版对照实验结果）

日期：2026-11-23。本报告取代 `CVF1B_CRITIC_RESULTS.md`（v1，已判定无效，见
[CVF1B_ERRATUM.md](CVF1B_ERRATUM.md)）。数据与训练全部复用 2026-11-20 的 Phase B
原始采集（44 起点 / 78,848 transitions），仅修正状态-标签合同后重建数据集（`datasets/v2/`，
schema `sacv_pairs_v2`）并重训。评估流程严格执行 ERRATUM §5 的预评估承诺：
Val（48 对 / 8 起点，reachable 32 对）做模型选择，Test（72 对 / 12 起点，reachable 48 对）
最后一次性盲评；训练前完成了协议 C4 要求的初始化测量。

## 0. 一句话结论

**修正状态对齐后，对照实验在方法上成立，裁定仍为 INCONCLUSIVE（负面倾向），但机制结论
完全改变**：(a) Sim 标量锚定（C1）真实改善了 held-out 标量价值精度（Test RMSE 0.684→0.497，
−27%）；(b) 任何监督都没有改善 policy 相关的 reachable 方向成对响应（T=96），Test 上全部
配对比较 CI 跨 0；(c) 显式 pair 监督（C2）在梯度平权剂量下明确有害（标量 RMSE +103–107%，
有剂量效应）；(d) 短时域（T=32）成对响应本来就准且两个 split 一致，而 T=96 的 ΔG 在新
clip 上与短时域信号大幅失相关（sp 0.45–0.58）——**瓶颈不在 critic 的局部拟合，而在
96 步续推差分目标在新 clip 上的可靠性**。

## 1. 实验设置（与 v1 的差异）

- critic 一律在前缀末端 x_H 上评价/训练（v1 误用 x_{H+96}）；`Delta_G` 与 `Delta_Y`
  分开存放（v1 把 ΔG 存进 `Delta_Y` 字段）；`c_T = ∏_{k<T}(1−d_k)` 修正；每个时域用
  各自的 V_ref(x_{H+T})；v1 数据集 fail-closed 拒载。回归测试
  `test_pairs_v2_state_label_alignment`（从原始步记录独立重算每个标签）通过。
- 初始化测量（Train，C-init，T=96）：L_value=0.649，L_pair=0.099，梯度范数
  g_value=13.73、g_pair=0.0265（比值 1/519），σ(ΔY_train)=0.319。
- C2 尺度两种预注册模式：`gradmatch`（g_value⁰/g_pair⁰=518.6，α 即 pair 梯度占比；
  主配置 α=0.3 → α_eff=155.6）与 `sigma2`（v1 协议的字面定义，α_eff=2.95，作敏感性）。
  变体：C1 / C0 / C2gm01 / C2gm03 / C2gm10 / C2sig03，各 1000 步，
  checkpoint 在 250/500/1000（`checkpoints/v2/`，含 init_scales 与合同元数据）。
- 训练输入一次性预计算（x_H 的 critic 输入），1000 步训练 ~2 分钟（v1 为 ~57 分钟）。
- 新增评估维度：弦平均 autograd 方向导数（policy 消费的是梯度）；无单侧终止层
  （nobif）；跨 ε gated 层；clip 聚类 bootstrap；Val/Test 的跨时域参考可靠性。

## 5. 机制结论（取代 v1 的"尾项淹没"叙事）

1. **瓶颈的定位改变了**：不在 critic 的局部拟合（T=32 响应本来就准、标量锚定有效），
   而在 **T=96 续推差分目标在新 clip 上的可靠性**。监督无法造出目标里没有的信息。
2. **显式 pair 监督在本数据规模（144 train pairs）下净有害**：梯度平权剂量以
   标量校准为代价（RMSE 翻倍）且无方向收益；旧尺度（α_eff≈3）则≈无效。
3. **WM 监督（C0）≈ 无操作**：WM 本就是从同一 simulator 拟合的，其 96 步续推目标
   相对 critic 自身信念几乎不含新信息（与 CVF-0 CF-B 一致）。
4. v1 声称的"尾项方差占 99.5%（163–203×）"是测量错误（错用 γ³² 且参考向量自指）；
   修正后 Train delta 族尾项方差为 ΔG 的 27–30×、Val/Test <0.25×。修正标签合同
   （v2）并未解锁 pair 学习——说明尾项不是主因，目标噪声才是。

## 6. Phase E 门禁

条件 ②（存在 Val 可信改善的候选）与 ⑤（正向机制信号）**再次失败**——且这次是在
方法有效的实验上失败。**CVF-2a 维持 NOT RUN。** `sacv_policy_update.py` 工具保持就绪。

## 7. 下一步（更新 CVF_NEXT_DECISION 的建议）

1. **噪声天花板量化**（纯 CPU，数据已在盘上）：逐 clip 把 ΔG₉₆ 与 ΔG₃₂/₆₄、接触切换
   指示（d_soft/d_hard 记录）关联，确定新 clip 上 96 步目标里"可预测成分"的占比；
   据此决定 pair 监督/评价应锚定哪个时域（T=32 的信号已证实充足）。
2. **把"改善"重新锚定到有信号的位置**：标量锚定已被证实（Test −27% RMSE）；若要
   追求方向响应，候选是 T=32 成对监督 + T=96 标量尾项的混合目标（本轮未测），
   或多段续推聚合的分布型目标。
3. **规模**：Val gated 8 对 / Test 6 对不支持 10pp 级门限的检验；任何后续 PASS 判定
   需要 gated ≥24 对（约 3× 起点）。
